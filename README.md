2. Clone your newly created repo (do not need if you already did this in the scope of previous tasks): https://autocode.git.epam.com/<%your_gitlab_username%>/js-for-ste/
3. Open your project folder
4. Switch to another branch: `git checkout variables_and_data_types`

6. Go to '.src/index.js' and do all the tasks from the file  
7. Run `npm run test:dev` in the command line  
8. You will see the number of passing and failing tests
